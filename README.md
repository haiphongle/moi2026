# Trang Web Tin Tức Giải Trí

Trang web tin tức giải trí tiếng Việt: phim ảnh, âm nhạc, sao Việt, K-Pop và TV show.

## Tính năng

- Dải tin nóng (hot-news ticker) chạy liên tục
- Bài viết nổi bật + mục "Đang đọc nhiều nhất"
- 9 bài viết thuộc các chuyên mục: Sao Việt / Phim Ảnh / Âm Nhạc / K-Pop / TV Show
- Lịch sự kiện giải trí trong tuần
- Bình chọn tương tác, form đăng ký nhận tin
- Lọc theo chuyên mục, tìm kiếm, lưu bài viết, đọc bài trong cửa sổ riêng
- Hỗ trợ giao diện sáng/tối theo hệ thống

## Cách chạy

Mở file `index.html` bằng trình duyệt là xem được ngay — toàn bộ hình ảnh đã được gộp sẵn trong file, không cần cài thêm gì.

## Đưa lên mạng miễn phí

- **GitHub Pages:** vào repo → Settings → Pages → mục Source chọn "Deploy from a branch" → chọn nhánh `main`, thư mục `/ (root)` → Save. Sau ~1 phút web có địa chỉ dạng `https://<ten-dang-nhap>.github.io/<ten-repo>/`
- **Vercel / Netlify:** kéo thả thư mục chứa file `index.html` vào trang deploy là có link công khai ngay.
